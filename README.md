## Why Self-Published

This dissertation was submitted in August 2025. The University of Exeter does not publish postgraduate taught dissertations, so I have chosen to self-publish it here. I do so because, on returning to the work, I find that its core arguments have not aged out — if anything, the questions it poses (who holds agency in human-LLM communication? how is meaning mediated? what must a user understand to engage critically?) have become more pressing as the technology has evolved. The hybrid framework was designed as a diagnostic toolkit rather than a fixed blueprint, and it is that orientation — identifying the right questions rather than prescribing answers — that I believe gives it continued relevance. Independent scholarly work published in the months following submission has, in several respects, converged with the framework's propositions, which is the clearest signal I have that the work still has something to contribute.

## Abstract

This dissertation addresses the critical theoretical gap in understanding human–Large Language Model communication by proposing a novel hybrid framework. This framework redefines agency as distributed across users, developers, providers, and models, and treats semantic noise, hallucinations, and context limits as structural features rather than errors; conceptualizes provider mediation (e.g., system prompts, RAG) as a new form of algorithmic agenda-setting; and integrates LLM Literacy—a human-centric competency model (Recognize, Resonate, Reflect, Responsible, Refine)—to empower users in co-constructing meaning amid probabilistic outputs.
