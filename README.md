## Abstract

This dissertation addresses the critical theoretical gap in understanding human–Large Language Model communication by proposing a novel hybrid framework. This framework redefines agency as distributed across users, developers, providers, and models, and treats semantic noise, hallucinations, and context limits as structural features rather than errors; conceptualizes provider mediation (e.g., system prompts, RAG) as a new form of algorithmic agenda-setting; and integrates LLM Literacy—a human-centric competency model (Recognize, Resonate, Reflect, Responsible, Refine)—to empower users in co-constructing meaning amid probabilistic outputs.
